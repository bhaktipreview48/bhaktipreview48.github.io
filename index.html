🤖 What This App Does

Think of the bot as a player who never panics. Every tick of the game, it receives two things: the current game state (its health, where enemies are, what it is holding, and more) and a list of possible options. It then chooses exactly one option and sticks with it for a short moment.

That short moment is about 0.35 seconds. In that window the bot commits to a tactic, such as holding an angle, peeking left, peeking right, strafe shooting, crouch spraying, falling back, pushing, reloading, or turning toward a sound. Alongside the tactic it picks a stance — running or walking — so its movement looks natural instead of robotic.

The result is a practice partner that feels deliberate. It does not spam actions or teleport around. It reads, decides, acts, then reads again.

🧩 How the Pieces Fit Together

You do not need to understand the plumbing, but knowing the three parts helps when something does not work.

1. The Game Side

On your Windows desktop, the CS:GO client talks to a local game server (srcds) running SourceMod. The bot body itself is a plugin file called jev_bot.smx. It handles the physical side of things: aiming, firing, reaction timing, reloading, and knowing the map spots.

2. The Bridge

A small helper called bridge.py runs on a desktop or MacBook. It sends the game state over UDP port 27500 and listens for the answer coming back.

3. The Brain

The brain is the part that decides. You can plug in different brains depending on how you want the bot to behave: rules (simple, predictable logic), julia, laya, local, or http (a remote decision service on your own network).

CS:GO client ↔ srcds + SourceMod (jev_bot.smx) ↔ UDP 27500 ↔ bridge.py ↔ brain

Step 1 — Get the Files

Open the download page in your browser and save the files to a folder you can find easily, such as your Desktop or a folder called csgo-julia-plugin. Do not rename or move individual files out of their folders afterwards.

Step 2 — Put the Bot Body in Place

Copy the plugin file jev_bot.smx into the SourceMod plugins folder of your local game server. This is the file that lets the bot actually aim, fire, and move.

Launch the server on your own machine with the -insecure setting. This keeps things private and makes clear the server is not connected to official matchmaking.

On your desktop or MacBook, run bridge.py. It will open port 27500 so the game side and the brain side can talk. If your computer asks for permission to allow the connection, accept it.

🎮 The Moves You Will See

Every 0.35 seconds the bot picks one of these tactics. You will start recognising them in game, which makes the bot a good tool for drilling your own reactions.

  • hold — stays put and watches an angle, waiting for you to appear.
  • peek_left — steps out to its left to take a look and maybe a shot.
  • peek_right — the same idea, the other way.
  • strafe_shoot — moves sideways while firing, so it is harder to hit.
  • crouch_spray — drops low and sprays, useful for close-range practice.
  • fall_back — retreats when the fight is going badly.
  • push — moves forward aggressively to take space.
  • reload — tops up the magazine before the next engagement.
  • face_sound — turns toward a noise it heard, just like a careful player would.

This project exists for practice and experimentation on a private network. To keep it that way:

  • Run the server only with -insecure.
  • Keep the bot and the bridge on machines you control.
  • Only play with people who said yes to testing with you.
  • Never take it into matchmaking, ranked queues, or public servers.

If you are unsure whether a server is public, treat it as public and do not connect.

🛠️ Common Fixes

The bot does not move at all

The brain side is probably not answering. Check that bridge.py is running and that port 27500 is not blocked by your firewall or another program.

The game server does not load the plugin

Re-check that jev_bot.smx is inside the plugins folder of SourceMod, and that SourceMod itself is installed for the server you are launching.

The bot behaves oddly or freezes

Switch to the rules brain for a quick test. If the bot moves normally with rules, the issue is with the brain you selected rather than the connection.

Friends cannot join

They need to be on the same network as your server. Confirm the server is reachable from another machine before you invite anyone.
